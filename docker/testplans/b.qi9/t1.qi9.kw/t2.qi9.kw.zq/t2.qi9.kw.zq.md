1. Create a temporary Python script at `/tmp/test_resolver.py` with a module docstring containing `## RESOLVER CONVENTION
Accepts a URL and returns its content.`
2. Run `bees set-resolver --name test_resolver --path /tmp/test_resolver.py --timeout 30`
3. Verify exit 0 and output contains `\"status\": \"success\"`
4. Run `bees get-resolvers`
5. Verify output contains an entry with `name: test_resolver`, `path: /tmp/test_resolver.py`, `timeout: 30`, `built_in: false`
6. Verify `file-path` entry is also present with `built_in: true`
