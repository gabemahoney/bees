1. Create two files: `echo "val1" > /tmp/ref_file1; echo "val2" > /tmp/ref_file2`
2. Create a bee with two entries: `bees create-ticket --ticket-type bee --title "Multi Ref" --hive <any> --reference-materials '[{"value":"/tmp/ref_file1"},{"value":"/tmp/ref_file2"}]'`
3. Verify exit 0
4. Run `bees show-ticket --ids <id>`
5. Verify `reference_materials` is a list of length 2
6. Verify first entry has `value == "/tmp/ref_file1"` and second has `value == "/tmp/ref_file2"`
7. Update to a single-entry list: `bees update-ticket --ids <id> --reference-materials '[{"value":"/tmp/ref_file1"}]'`
8. Verify `show-ticket` now returns `reference_materials` of length 1
