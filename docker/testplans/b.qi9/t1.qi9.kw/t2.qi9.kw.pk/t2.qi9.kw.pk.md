1. Create a resolver script at `/tmp/custom_resolver.sh`:
   ```bash
   #!/bin/bash
   VALUE=""
   while [[ $# -gt 0 ]]; do
       case $1 in
           --value) VALUE="$2"; shift 2 ;;
           --repo-root) shift 2 ;;
           *) shift ;;
       esac
   done
   echo "{\"resolved\": true, \"original\": \"$VALUE\"}"
   ```
   Make it executable: `chmod +x /tmp/custom_resolver.sh`
2. Register: `bees set-resolver --name custom_res --path /tmp/custom_resolver.sh`
3. Colonize a hive with `--allowed-resolvers '["custom_res"]'`
4. Create a bee: `bees create-ticket ... --reference-materials '[{"value":"test_value","resolver":"custom_res"}]'`
5. Verify exit 0
6. Run `bees show-ticket --ids <id>`
7. Verify `reference_materials[0]["resolved"]["resolved"]` is `true` (resolver was invoked and returned its JSON)
8. Verify `reference_materials[0]["resolved"]["original"]` is `"test_value"`
