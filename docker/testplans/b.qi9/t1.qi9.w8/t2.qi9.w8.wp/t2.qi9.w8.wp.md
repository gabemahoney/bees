Write an invalid elevated_repos entry (e.g. an entry missing the required path key) to ~/.bees/config.json. Run bees list-hives. Verify the command fails with an error that indicates invalid_config (error type or message). The error should clearly identify the problem with the elevated_repos configuration.

Run this test from a clean working directory that has no registered hives. The error should appear regardless of whether any hives are defined.
