Write a valid elevated_repos entry to ~/.bees/config.json where the path points to a directory that does not exist on disk (e.g. /nonexistent/path/does/not/exist). Run bees list-hives. Verify the command succeeds without error. No hives should be reported from the elevated_repos entry (since the path doesn't exist), and no error should occur.

This confirms that elevated_repos path resolution is non-fatal: missing directories are silently ignored.
