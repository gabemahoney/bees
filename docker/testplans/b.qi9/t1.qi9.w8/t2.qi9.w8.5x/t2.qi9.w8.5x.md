Configure two scopes with separate hives and register a queen repo in elevated_repos. When listing hives with the MCP roots protocol pointing to the queen repo but the repo_root parameter pointing to a non-elevated repo, confirm that the queen's elevation wins and all hives from all scopes are returned. Using repo_root alone (without roots context) from the non-elevated repo should return only the matching scope's hives.
