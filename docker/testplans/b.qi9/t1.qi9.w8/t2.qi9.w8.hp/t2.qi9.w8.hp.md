**Setup:** Two overlapping scopes exist in config — e.g. `/projects/**` and `/projects/project_a/`.

**Action:** Colonize a hive with the same name (e.g. "bugs") at the second scope when it already exists at the first.

**Expected:** `cross_scope_hive_conflict` error. The error message must name both the conflicting scope and the target scope.
