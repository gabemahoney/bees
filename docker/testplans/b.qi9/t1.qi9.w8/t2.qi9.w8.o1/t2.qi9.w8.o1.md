**Setup:** Two scopes in config: a broad wildcard scope (`/projects/**`) that defines hive "bugs", and a narrower exact scope (`/projects/project_a/`) that defines hive "backend". No hive name conflict.

**Action:** Run `bees list-hives` from a repo at `/projects/project_a/`.

**Expected:** Both "bugs" (from the parent wildcard scope) and "backend" (from the exact scope) appear in the output. The parent-scope hive is visible alongside the child-scope hive.

**Regression note:** Before the multi-scope fix in `get_scoped_config()`, only the most-specific scope was consulted, so "bugs" would be invisible. This test guards against that regression.
