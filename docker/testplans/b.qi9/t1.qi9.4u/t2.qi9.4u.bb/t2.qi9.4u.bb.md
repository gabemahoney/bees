Test Area covering how `create_ticket` and `update_ticket` store an inline `body` that holds the two-character sequences backslash-n and backslash-t, as an LLM sends them when it double-escapes JSON. The MCP tools store a real newline and a real tab, not the two characters. Before this was fixed, such bodies were stored verbatim.

Transport: HTTP. Self-contained — colonizes `escape_http_hive` at the start.

Pre-condition: MCP server running on port 9000, registered as "bees-http".
