**Steps:**
1. Call `colonize_hive` with `name="escape_http_hive"`, `path="/test-repo/tickets/escape_http"` via HTTP transport.
2. Call MCP tool `create_ticket` via HTTP with `ticket_type="bee"`, `title="Escape Bee"`, `hive="escape_http_hive"` and `body` set to `line one\nline two`, where `\n` is the two characters backslash and `n`, not a newline (as a JSON argument: `"line one\\nline two"`). Save the returned `ticket_id` as ESCAPE_BEE.
3. Call `show_ticket` with ESCAPE_BEE via HTTP transport.
4. Call `update_ticket` via HTTP with `ticket_ids` set to ESCAPE_BEE as a single string (not a list: `body` works only in single-ticket mode) and `body` set to `col one\tcol two`, where `\t` is the two characters backslash and `t`, not a tab (as a JSON argument: `"col one\\tcol two"`).
5. Call `show_ticket` with ESCAPE_BEE via HTTP transport.

**Expected:** Colonize succeeds. Both tool calls succeed. In step 3 the body is `line one`, a real newline, `line two`: the JSON response reads `"line one\nline two"`, not `"line one\\nline two"`. In step 5 the body is `col one`, a real tab, `col two`: the JSON response reads `"col one\tcol two"`, not `"col one\\tcol two"`.
