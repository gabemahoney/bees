**Steps:**
1. Call `update_ticket` on PA with `priority=1.5`, then `priority=true`, then `priority="2"` (a string).
2. Call `create_ticket` for a bee titled "Never Written" in `priority_http_hive` with `priority=1.5`.
3. Call `show_ticket` on PA, and query `priority_http_hive` for `title~Never Written`.

**Expected:** Every call in steps 1 and 2 returns an error with error_type `invalid_priority`. PA still has priority 2, and no "Never Written" ticket exists.
