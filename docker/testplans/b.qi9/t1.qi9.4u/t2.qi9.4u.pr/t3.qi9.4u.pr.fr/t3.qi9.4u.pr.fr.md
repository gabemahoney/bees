**Steps:**
1. Call `colonize_hive` to create a hive "Priority HTTP Hive" (`priority_http_hive`) with child tiers t1=Task/Tasks.
2. Call `create_ticket` in it for: bee PA with `priority=2`, t1 TA under PA with `priority=1`, bee PB with `priority=0`, bee PC with `priority=-1` (each priority an integer, not a string).
3. Call `create_ticket` without `priority` for: bee PD with `tags=["priority:1"]`, and t1 TD under PD.
4. Call `show_ticket` with all six IDs.

**Expected:** Every call succeeds. The priorities shown are PA 2, TA 1, PB 0, PC -1, PD null and TD null. PD's tags are `["priority:1"]`. Save the six IDs for the later tests of this Test Area.
